# Prompts de prueba (Anexo B del Plan de Pruebas)

Prompt versionado. Modelo del ciclo: `opencode-go/gpt-6-luna` (variant: max). No cambiar el modelo dentro de un ciclo (sección 10.7 del plan).

## P-01 — Flujo autónomo (CP-02)

Usa el servidor playwright. Navega a https://demo.playwright.dev/todomvc y prueba de forma autónoma la aplicación de lista de tareas. Debes: (1) agregar tres tareas; (2) completar una; (3) editar otra con doble clic; (4) eliminar una; (5) usar los filtros Todas, Activas y Completadas; (6) limpiar las completadas. Después de cada paso toma un snapshot, verifica el contador de elementos y guarda una captura en ./evidencias. Al final entrega una tabla con paso, resultado esperado, resultado obtenido, veredicto (Aprobado o Fallido) y archivo de evidencia. No ejecutes código arbitrario ni visites otros sitios.
