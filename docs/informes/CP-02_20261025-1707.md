## Hallazgos técnicos de esta corrida

1. **Clave de persistencia real: `react-todos`** (no `todos`). Registros CP-13 (persistencia) y la línea base manual deben usarla.
2. **Todos los ítems renderizan `input.edit` oculto**: selectores como `input.edit` o `.todo-list li.editing input` violan strict-mode; el patrón único es `.todo-list li.editing input.edit` (o rol "Edit" dentro del ítem). Anotar en la especificación de casos de CP-09.
3. **Botón eliminar**: accesible como `button.destroy`, invisible sin hover sobre el ítem (el snapshot lo muestra como texto "×"); el clic funciona tras hover o por selector directo.
4. **Contador**: cubre singular/plural ("1 item left" / "N items left") — datos útiles para CP-06.
5. `--isolated` no estaba activo: el perfil quedó persistente con estado final (1 tarea activa); limpiar estado antes de la próxima corrida (borrar `react-todos` o usar la config del repo).
